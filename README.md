2. PROJECT DESCRIPTION
----------------------
This application is a Java Swing desktop program that simulates 
the 5 core steps of the ISO/IEC 15939 software measurement 
process standard. It allows for defining quality 
dimensions, selecting scenarios, collecting metric data, 
and performing gap analysis.

3. COMPILATION AND RUN INSTRUCTIONS
-----------------------------------
This project has no IDE dependency and uses only standard 
Java SE libraries.

To compile the project from the command line:
1. Open your terminal/command prompt.
2. Navigate to the 'src' directory of the project.
3. Run the following command:
   javac *.java 

To run the project:
1. After compilation, run the following command:
   java Main
